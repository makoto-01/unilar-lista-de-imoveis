# UniLar — Lista de Imóveis
Protótipo front-end do frame **“02 - Lista de Imóveis”**.

## Arquivos
- `index.html`: estrutura da página.
- `style.css`: estilos e adaptação para telas menores.
- `script.js`: imóveis demonstrativos e interações.

## Como testar
Abra `index.html` no navegador. A busca, os filtros por tipo/preço/região, a ordenação, os favoritos e a janela de detalhes são interativos.

## Observações
- Imóveis, preços e descrições são fictícios.
- Fotos e fontes são carregadas de serviços externos e precisam de internet.
- O mapa é ilustrativo, não representa ruas reais.
- “Tenho interesse” apenas mostra uma mensagem; não envia contato.
- Favoritos permanecem somente enquanto a página está aberta.
- A marca tipográfica é provisória; troque pelo arquivo oficial do logo UniLar para preservar exatamente o logo do Figma.
